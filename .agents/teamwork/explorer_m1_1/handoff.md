## 2. Logic Chain

### 2.1 Dual-Target Crate Architecture (`[lib]` + `[[bin]]`)
1. **Premise**: The project requires both an operational CLI binary (`rfb-cnpj-etl`) and an automated test suite (`tests/e2e_pipeline_test.rs` and unit tests) validating synthetic fixtures.
2. **Mechanism**: Structuring `Cargo.toml` with `[lib] (name = "rfb_cnpj_etl")` and `[[bin]] (name = "rfb-cnpj-etl")` allows integration tests to directly call Rust internal modules (e.g. `rfb_cnpj_etl::downloader`, `rfb_cnpj_etl::ingestion`, `rfb_cnpj_etl::graph`) without shelling out to a binary for every invariant check.
3. **Inference**: The binary in `src/main.rs` serves as a clean, thin CLI wrapper delegating to `rfb_cnpj_etl::cli::run()`.

### 2.2 Complete Lifecycle Dependency Set
1. **Premise**: The project has four operational phases across Milestones 1 through 4:
   - M1: Async resumable HTTP 206 download with WebDAV discovery and progress bars.
   - M2: High-throughput streaming decompression, in-memory CSV transformation, and SQLite batch loading.
   - M3: Multi-database attached relational graph joins, FTS5 virtual table indexing.
   - M4: Database inspection, table row counting, and machine-readable JSON status reporting.
2. **Selection of Crates**:
   - `clap = { version = "4.5", features = ["derive", "env"] }`: Type-safe CLI parsing with subcommand routing and environment variable fallback.
   - `tokio = { version = "1.40", features = ["rt-multi-thread", "macros", "fs", "io-util", "time", "sync"] }`: Asynchronous runtime for concurrent downloads, retries, and timers.
   - `reqwest = { version = "0.12", default-features = false, features = ["rustls-tls", "stream", "json"] }`: Fast async HTTP client with byte streaming support and pure-Rust TLS (no system OpenSSL dependencies).
   - `futures-util = "0.3"`: Stream combinators (`StreamExt`) for processing incoming HTTP byte chunks.
   - `indicatif = { version = "0.17", features = ["rayon"] }`: Terminal progress bars and spinners (`MultiProgress`) with speed, ETA, and byte counters.
   - `rusqlite = { version = "0.32", features = ["bundled", "fts5", "backup", "blob"] }`: Bundles modern SQLite C engine with compile-time FTS5 and Backup API support.
   - `zip = { version = "2.2", default-features = false, features = ["deflate"] }`: In-memory streaming decompression directly into CSV readers.
   - `csv = "1.3"`: Fast semicolon-delimited record parsing via `ByteRecord`.
   - `encoding_rs = "0.8"`: High-speed conversion from RFB's `Windows-1252` to UTF-8.
   - `crossbeam-channel = "0.5"`: Bounded channels for decoupling decompression from SQLite write transactions, enforcing memory ceiling < 1.8 GB RAM.
   - `rayon = "1.10"`: CPU-bound parallel processing for decompression/parsing across worker threads.
   - `memmap2 = "0.9"`: Zero-copy memory mapping for reading large archives.
   - `anyhow = "1.0"`: Top-level ergonomic error reporting for CLI dispatch.
   - `thiserror = "1.0"`: Strongly typed internal error enums (`DownloadError`, `IngestionError`, `GraphError`).
   - `tracing` + `tracing-subscriber`: Structured logging and diagnostic observability.
   - `regex = "1.11"`: Regex parsing for WebDAV PROPFIND responses and filenames.
   - `quick-xml = { version = "0.37", features = ["serialize"] }`: Robust streaming XML parsing for WebDAV listings.
   - `serde` + `serde_json`: Machine-readable JSON reporting for `rfb-cnpj-etl status --format json`.
   - `chrono = { version = "0.4", features = ["serde"] }`: Reference date and timestamp handling.

### 2.3 Memory Bounding Design (< 1.8 GB RAM Guarantee)
1. **Premise**: Requirement R1/R2 mandates execution on 8GB-16GB machines without swapping or OOM.
2. **Mechanism**:
   - SQLite cache: Configured via `PRAGMA cache_size = -500000;` (~500 MB).
   - Ingestion channels: `crossbeam_channel::bounded(16)` with 5,000-row chunks (~40 MB resident).
   - In-memory CSV streaming: `ByteRecord` buffer re-use per thread (~2 MB per thread).
   - Rayon threads (4 workers): ~64 MB.
3. **Inference**: Total process resident memory is capped at ~1.0 GB to 1.5 GB. The CLI includes a `--memory-limit-mb` parameter that dynamically scales `PRAGMA cache_size` and channel buffer bounds.

            page_size: 4096,
            cache_size_kib: -500_000, // 500 MB
            threads: 4,
            temp_store_memory: true,
        }
    }
}

impl IngestionPragmas {
    /// Calculate PRAGMAs dynamically from a given total memory limit in MB.
    pub fn from_memory_limit(memory_limit_mb: usize, worker_threads: usize) -> Self {
        // Allocate approximately 40% of the budget to SQLite page cache
        let cache_mb = (memory_limit_mb as f64 * 0.40).max(128.0) as i64;
        Self {
            page_size: 4096,
            cache_size_kib: -cache_mb * 1024,
            threads: worker_threads.clamp(1, 8) as u32,
            temp_store_memory: true,
        }
    }

    /// Apply high-throughput ingestion PRAGMAs to an active SQLite connection.
    pub fn apply_to(&self, conn: &rusqlite::Connection) -> rusqlite::Result<()> {
        conn.execute_batch(&format!(
            "PRAGMA page_size = {};
             PRAGMA journal_mode = OFF;
             PRAGMA synchronous = OFF;
             PRAGMA cache_size = {};
             PRAGMA temp_store = {};
             PRAGMA locking_mode = EXCLUSIVE;
             PRAGMA foreign_keys = OFF;
             PRAGMA auto_vacuum = NONE;
             PRAGMA threads = {};",
            self.page_size,
            self.cache_size_kib,
            if self.temp_store_memory { "MEMORY" } else { "FILE" },
            self.threads,
        ))
    }

    /// Apply production post-load PRAGMAs (WAL mode, normal synchronous).
    pub fn apply_post_load(conn: &rusqlite::Connection) -> rusqlite::Result<()> {
        conn.execute_batch(
            "PRAGMA optimize;
             PRAGMA journal_mode = WAL;
             PRAGMA synchronous = NORMAL;
             PRAGMA locking_mode = NORMAL;",
        )
    }
}

//! Binary entry point for `rfb-cnpj-etl`.

use anyhow::Result;
use clap::Parser;
use rfb_cnpj_etl::cli::{Cli, Commands, OutputFormat};
use tracing::Level;
use tracing_subscriber::{fmt, EnvFilter};

#[tokio::main]
async fn main() -> Result<()> {
    let cli = Cli::parse();

    // Configure logging based on verbosity flags
    let log_level = match (cli.quiet, cli.verbose) {
        (true, _) => Level::ERROR,
        (false, 0) => Level::INFO,
        (false, 1) => Level::DEBUG,
        (false, _) => Level::TRACE,
    };

    let filter = EnvFilter::default()
        .add_directive(format!("rfb_cnpj_etl={}", log_level).parse()?)
        .add_directive(format!("rfb_cnpj_etl::main={}", log_level).parse()?);

    fmt()
        .with_env_filter(filter)
        .with_target(false)
        .init();

    match cli.command {
        Commands::Download(args) => {
            rfb_cnpj_etl::downloader::run(args).await?;
        }
        Commands::BuildCnpj(args) => {
            rfb_cnpj_etl::ingestion::run(args)?;
        }
        Commands::BuildRede(args) => {
            rfb_cnpj_etl::graph::run(args)?;
        }
        Commands::Status(mut args) => {
            if args.json {
                args.format = OutputFormat::Json;
            }
            rfb_cnpj_etl::status::run(args)?;
        }
    }

    Ok(())
}
